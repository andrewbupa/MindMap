# Highlighted

The phrase highlight: a tint of the label's family, its strength set by the panel's median intensity. Hover or focus shows the label and intensity; choosing it opens the FindingPane.

Provide `family`, `label`, `median` (0 to 3, halves allowed), `children` (the quoted phrase), and optionally `judges`, `selected` and `onSelect`.

- Where phrases overlap, render only the strongest.
