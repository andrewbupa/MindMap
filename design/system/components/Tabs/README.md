# Tabs

A groove of tabs with a raised lozenge on the selected one; Jury's three queues use it.

Provide `tabs` (`{id, label, count?}`), `label` (what the set is), and either `panels` (an object of id to content) or `value` with `onChange`.

- Arrow keys, Home and End move between tabs.
- Counts sit beside the label in tabular figures.
