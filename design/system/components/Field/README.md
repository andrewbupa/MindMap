# Field

A labelled text input or text area, set into a shallow well.

Provide `label`, and optionally `hint`, `error`, `multiline`, `id`, plus any input props (`value`, `onChange`, `placeholder`).

- Every field has a visible label; hints sit under the control, errors replace nothing and say how to fix the problem.
- The well (`color-channel`, `shadow-inset`) has a `color-border-strong` edge so the control meets 3:1.
