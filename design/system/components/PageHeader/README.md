# PageHeader

Title, a short intro and an optional quiet line, with the Relief motif in its own column on the right. The motif never sits under text, and hides below 900px.

Provide `title`, and optionally `intro`, `note` (the quiet line, such as Lens's fixed wording), `area` (the page's area, for analytics and future variation; every area draws the same route today) and `actions`.

- This is where the channel motif is boldest; keep everything else on the page quiet.
- Lens pages must pass `note`: "Expressed disposition, read from text. Lens does not see inside the model."
