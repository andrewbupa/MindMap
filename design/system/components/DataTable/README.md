# DataTable

A sortable table with a sticky header, tabular figures and two densities.

Provide `columns` (`{key, label, align?, render?, sortValue?, sortable?}`), `rows`, and optionally `density` (`comfortable` or `dense`), `caption`, `initialSort` (`{key, dir}`), `rowHeaders` and `maxHeight`.

- Right-align numbers. Links stay underlined so they read as links in dense rows.
