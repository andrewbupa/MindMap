# Seeds

- `petri/`: our Petri seed instructions (markdown, tagged by domain and risk) and custom judge dimensions. Milestone 3.
- `bloom/`: one folder per behaviour with `seed.yaml`, `behaviors.json` and `models.json`. Milestone 4.
- `ethos/`: `taxonomy.yaml`, `expected_profiles.yaml` and the gold set. Milestone 5.

Every run stores the hash of the seed files it used.
